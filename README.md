# orders-mini-sync

Мини-синхронизатор заявок: забирает «сырые заявки» из `https://test.ooobs.ru/api/orders`,
нормализует телефоны, дедуплицирует по телефону и отдаёт результат в JSON.

## Логика

- **Телефон** → `+7xxxxxxxxxx`: из строки берутся только цифры; 11 цифр,
  начинающихся с `7` или `8`, приводятся к `+7…`. Всё, что не сводится к 11
  цифрам (пустые, короткие, текст, 10-значные), отбрасывается как невалидное.
- **Дедуп по телефону**: остаётся запись с максимальным `amount`;
  при равном `amount` — более поздняя по `created_at`.
- **Идемпотентность**: результат — чистая функция от источника; повторные
  запуски синхронизации (`GET/POST /sync`) возвращают тот же JSON,
  дубли не плодятся. Ответ кешируется на `CACHE_TTL` секунд (по умолчанию 300).

## Эндпоинты

- `GET /result` — итоговый JSON по схеме `{ "clients": [...], "stats": {...} }`
- `GET|POST /sync` — принудительная повторная синхронизация (идемпотентна)
- `GET /` — служебная информация

## Запуск локально

```bash
pip install -r requirements.txt
uvicorn api.index:app --host 0.0.0.0 --port 8000
```

## Деплой

- **Render**: подключить репозиторий — `render.yaml` подхватится автоматически.
- **Railway/Fly**: build `pip install -r requirements.txt`,
  start `uvicorn api.index:app --host 0.0.0.0 --port $PORT`.
- **Vercel**: `vercel deploy --prod` — `vercel.json` уже настроен
  (Python FastAPI в `api/index.py`).

## Конфигурация

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SOURCE_URL` | `https://test.ooobs.ru/api/orders` | Источник заявок |
| `CACHE_TTL` | `300` | Секунды кеша результата |

Секретов в коде нет — источник публичный; при необходимости токены
передаются только через переменные окружения платформы.
